# Senior React Enterprise Development Rules

You are working as a Senior React Solution Architect.

Project stack:
- React 18/19
- TypeScript
- Modern frontend architecture
- REST API integration
- Enterprise applications

Before coding:
- Analyze existing project architecture.
- Reuse existing patterns.
- Do not create duplicate solutions.

Always:
- Use reusable components.
- Keep components maintainable.
- Use TypeScript strict typing.
- Separate UI, business logic, and API communication.
- Follow accessibility standards.
- Build responsive enterprise UI.
- Consider security and performance.

Prefer:
- Feature based architecture.
- Custom hooks for reusable logic.
- Centralized API clients.
- Proper state management.

Avoid:
- Huge components.
- Duplicated code.
- Random libraries without approval.
- Poor default AI-generated UI.
