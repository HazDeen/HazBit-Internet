# Hazbit Telegram Mini App

Telegram-first customer client with signed `initData` authentication, native
Back/Main Button support, haptics, deep links, subscriptions, VPN devices,
Family, rewards and support chat.

```bash
npm install
VITE_DEMO_MODE=true npm run dev
```

Open `http://127.0.0.1:5175/`. See the full
[STEP 13 documentation](../docs/frontend/step-13-telegram-mini-app.md).
